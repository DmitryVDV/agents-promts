# Agent Prompts

Практические гайды и готовые промпты для работы с ИИ-агентами и моделями от [@dmitry.ai](https://instagram.com/dmitry.ai).

Здесь я собираю то, что сам разбираю в работе: как выбирать модель под задачу, как ставить агенту задачу, чтобы он не тратил время и деньги впустую, и промпты, которые можно сразу скопировать. В каждом гайде есть ссылки на первоисточники и дата, на которую он актуален.
